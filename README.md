### 6. MVP 最小可运行产品（全栈）
**真正可运行的全栈源代码**，包含后端API服务、SQLite数据库、前端页面。

后端（Python Flask + SQLite）：
- `backend/app.py` — 9个RESTful API（房态/入住/协同任务/统计）
- `backend/db.py` — 数据库表结构 + 100间房种子数据
- 房态联动：离店自动生成清洁任务

前端（原生HTML/CSS/JS）：
- **房态看板**：5层楼实时房态矩阵，点击修改房态
- **入住办理**：录入信息、选房、办理入住
- **协同任务**：工单创建/接单/完成
- **入住记录**：查看历史记录
- 双模式：后端在线时走真实API，离线时自动降级到localStorage

启动方式：
```bash
cd 06-MVP/backend
pip install -r requirements.txt
python app.py
# 浏览器访问 http://127.0.0.1:5001/
```
Windows用户可双击 `backend/start.bat` 一键启动。

## 🚀 快速开始

1. **运行MVP（推荐）**：进入 `06-MVP/backend/`，执行 `pip install -r requirements.txt && python app.py`，浏览器访问 http://127.0.0.1:5001/
2. **MVP离线模式**：双击 `06-MVP/frontend/index.html` 用浏览器打开
3. **查看实验室系统**：双击 `01-业务挖掘-实验室系统/index.html`
4. **查看流程图**：双击 `03-流程图/` 下的HTML文件
5. **查看文档**：用Word打开 `.docx` 文件
